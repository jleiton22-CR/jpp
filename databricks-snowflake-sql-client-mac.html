A Databricks and Snowflake SQL client for Mac, inside your code editor

Last updated: 2026-11-21

The full version of jplus2 connects to Databricks and Snowflake through their own SQL APIs. You write the query next to your code, press a shortcut, and read the results in a grid.

What you can connect to

  • Databricks on Azure, AWS and GCP.
  • Snowflake.

Both use their own SQL APIs, so there is no command line client to install first. The same SQL tab also works with Azure SQL, SQL Server and Synapse, PostgreSQL, MySQL and MariaDB, SQLite files, and Excel and CSV files.

How it works

  1. Choose Database ▸ Manage Connections… (⇧⌘D) and add a Databricks or Snowflake connection.
  2. Open a SQL tab and write your query.
  3. Press ⌘↩ to run the selection, or the statement at the caret.
  4. The results appear in a grid under your code. Copy them, or export them as CSV.

Passwords, tokens and API keys are kept in the macOS Keychain.

Why use an editor for this

Notebooks and web consoles keep the query away from the script that uses it. In jplus2 the SQL, the Python or shell code around it, GitHub and the AI assistant are in one window, so you can query a warehouse, adjust a script and commit the change without switching apps.

Asistente de IA Solo versión completa

Un asistente que ve lo que tú ves, y que puede trabajar por ti.

Haz una pregunta y el asistente lee el archivo que tienes delante y tu selección. Activa el modo Agente y además puede recorrer tu proyecto, proponer cambios en archivos y proponer comandos de terminal, paso a paso, y tú apruebas cada uno.

  • Modo Agente: lee archivos, muestra cada cambio como diff para Aplicar o Cancelar y muestra cada comando en el panel Terminal con Run y Reject; la salida vuelve al asistente
  • Lee AGENTS.md, CLAUDE.md o .cursorrules de tu proyecto y guarda memorias por proyecto. Escribe @ para traer archivos, pestañas abiertas (incluso sin guardar), rangos de líneas, terminales, el diff, la rama o una conversación anterior
  • Revisa cambios sin confirmar o pull requests, y ejecuta tus propios prompts desde ai-commands.json
  • Claude con tu propia clave de API, cualquier servicio compatible con OpenAI (incluido un modelo local como Ollama) o un gateway de empresa
  • Guarda tus conversaciones: reábrelas, búscalas y expórtalas como Markdown. Cambia entre modelos de Claude desde un menú bajo el chat
  • Nuevo en 1.0.1: sugerencias en línea (desactivadas por defecto): las siguientes líneas aparecen en gris mientras escribes. Tab las acepta, Option-Derecha toma una palabra y Escape las descarta
  • Nuevo en 1.0.1: servidores MCP. Conecta el agente a servidores de herramientas por HTTP; cada llamada pide tu aprobación antes
  • Solo en la versión completa: nada de esto está en jplus2 Lite

Editar Lite y Completa

Un editor que te sigue el ritmo.

El motor de edición es Scintilla, conocido por su rapidez con archivos grandes. A su alrededor, jplus2 añade las herramientas que usas todo el día.

  • Resaltado de sintaxis y plegado de código para 95 lenguajes
  • Cursores múltiples, edición en columna, macros y marcadores
  • Buscar, reemplazar y marcar con expresiones regulares en todos los archivos abiertos
  • Un explorador de archivos que se actualiza cuando la carpeta cambia
  • Barras de iconos que muestras u ocultas una a una (Edición, Código, Vista, Paneles) y una barra de estado que puedes ocultar
  • 16 codificaciones de texto, con Reopen with Encoding, y Comparar dos archivos como diff
  • Restauración de la sesión que conserva hasta el texto sin guardar
  • Pestañas que marcan los cambios sin guardar y se pueden arrastrar para reordenar. Apariencia Match macOS, Light o Dark

Ir a cualquier cosa Lite y Completa

Escribe unas letras. Ya estás ahí.

Pulsa ⌘P y escribe. jplus2 encuentra un archivo con unas pocas de sus letras en orden, así que mpy encuentra src/main.py, y nombre:42 lo abre en la línea 42.

  • En el mismo panel, @ muestra los símbolos del archivo, : va a una línea y # busca texto
  • La paleta de comandos (⇧⌘P) ejecuta cualquier comando de los menús por su nombre, y muestra dónde está y su atajo
  • Un minimapa de todo el archivo junto al editor: haz clic o arrastra sobre él para desplazarte

IntelliSense Solo versión completa

Conoce tu código.

Autocompletado mientras escribes, ayuda de parámetros, descripciones al dejar el puntero sobre un nombre y subrayado de errores y advertencias.

  • C, C++, Objective-C y Swift funcionan de inmediato, con los servidores de lenguaje que trae Xcode
  • Python funciona sin ningún servidor: jplus2 lee tu archivo y tus módulos instalados
  • Go, Rust, TypeScript, Java, Ruby, Lua y más se usan cuando sus servidores están en tu Mac

Ejecutar y depurar Solo versión completa

Pulsa F5. En cualquier lenguaje.

Compilar y Ejecutar funcionan con todos los lenguajes del menú. La salida aparece debajo de tu código y, tras un error, el cursor salta a la línea que indica el compilador.

  • Un depurador de Python con puntos de interrupción, ejecución paso a paso, las variables del marco y un campo de expresiones
  • Comprobaciones integradas para JSON, XML, YAML, TOML, HTML, CSS y más
  • Manage Compilers muestra lo que está instalado y descarga lo que falta con Homebrew, npm o pip
  • Un terminal integrado de verdad (⌃`): tu propio shell, con vim, el REPL de Python y Control-C funcionando, y varios terminales en pestañas. Configure Commands sustituye los comandos de compilar y ejecutar de un lenguaje por los tuyos
  • Nuevo en 1.0.1: Buscar en carpeta (⇧⌘F) busca en todos los archivos de texto de una carpeta, con filtros, palabra completa y expresiones regulares. Reemplazar todo muestra antes qué va a cambiar, hace copia de los archivos que reescribe, y Undo Last Replace los restaura
  • Nuevo en 1.0.1: Scripts. Automatiza ediciones con tu propio JavaScript sobre el documento abierto. Un script no tiene acceso a la red, a archivos ni al shell, y cada ejecución es un solo paso de deshacer

Bases de datos Solo versión completa

Databricks y Snowflake, justo al lado de tu código.

Guarda una conexión a Databricks o Snowflake una vez y pulsa ⌘↩ en una pestaña SQL. Los resultados llegan a una tabla que puedes copiar o exportar como CSV (desde la versión 1.0.1, también como Excel .xlsx o JSON). Se conectan mediante sus propias API de SQL, así que no hay que instalar ninguna herramienta cliente.

  • Databricks en Azure, AWS y GCP
  • Snowflake
  • Azure SQL, SQL Server y Synapse
  • PostgreSQL (incluido Azure Database for PostgreSQL)
  • MySQL y MariaDB (incluido Azure Database for MySQL)
  • Archivos SQLite, sin instalar nada
  • Libros de Excel y archivos CSV: cada hoja se convierte en una tabla
  • Nuevo en 1.0.1: Export guarda los resultados como CSV, libro de Excel o JSON, en Descargas y con un nombre con fecha
  • Versión del Mac App Store: no ofrece las conexiones a Azure SQL, SQL Server, Synapse, PostgreSQL, MySQL ni MariaDB

GitHub Solo versión completa

De explorar a fusionar, sin salir.

Conecta tu cuenta y jplus2 muestra tus repositorios. La barra de estado indica la rama, lo que hay por enviar o recibir y cuántos archivos cambiaron.

  • Explora las carpetas y los archivos de tus repositorios sin clonarlos
  • Crea un pull request y fusiónalo con merge, squash o rebase
  • Clonar, confirmar, enviar, recibir y actualizar
  • Publica una carpeta en un repositorio nuevo, crea un gist o copia un enlace a la línea actual

    Preguntas frecuentes

    Preguntas antes de descargar

    ¿Qué diferencia hay entre Lite y la versión completa?
    Lite es un editor gratuito de 5,6 MB para texto y código cotidianos en 95 lenguajes. La versión completa, una compra única de $19.99 en la Mac App Store, añade el terminal integrado, IntelliSense, compilar y ejecutar, el depurador de Python, SQL sobre CSV, Excel y bases de datos, GitHub y el agente de IA. No hay suscripción.
    ¿jplus2 envía mi código a algún sitio?
    No. jplus2 no recopila datos y no tiene cuentas ni anuncios. Tu código va a GitHub, a una base de datos o a un modelo de IA solo cuando tú lo pides (o, en el caso del modelo, mientras tengas activadas las sugerencias en línea), directamente desde tu Mac y con la cuenta que conectaste.
    ¿Qué modelos de IA puedo usar?
    Tu propia clave de la API de Claude, cualquier servicio compatible con OpenAI o un modelo que se ejecute en tu Mac con Ollama. El agente propone cada edición como diff y cada comando en el panel Terminal, y no ocurre nada hasta que lo apruebas.
    ¿Es seguro abrir la descarga gratuita de Lite?
    Desde la versión 1.0.2, jplus2 Lite está firmada con el Developer ID del desarrollador y notarizada por Apple, que comprueba que no contenga software malicioso. La primera vez, macOS puede pedirte que confirmes que quieres abrir una app descargada de internet. La página de descarga muestra el SHA-256 para que verifiques el archivo.
    ¿En qué se diferencia jplus2 de VS Code o Sublime Text?

Descripciones que puedes copiar

Una línea

jplus2 es un editor de código rápido y nativo para Mac, con una versión Lite gratis.

Corta (unas 60 palabras)

jplus2 es un editor de código nativo para macOS, basado en Scintilla 5 para Mac con Apple Silicon e Intel. La versión Lite, gratis, cubre la edición diaria en 95 lenguajes, sin cuenta y sin telemetría. La versión completa, que llega al Mac App Store, añade ejecutar y depurar, SQL sobre archivos CSV y Excel, GitHub y un asistente de IA que usa tu propia clave de API o un modelo local.

Larga (unas 110 palabras)

jplus2 es un editor de código nativo para macOS, escrito en Cocoa sobre el componente de edición Scintilla 5 y hecho por un solo desarrollador, Jason Leiton. La versión Lite, gratis y de unos 5.6 MB, ofrece resaltado de sintaxis y plegado para 95 lenguajes, pestañas con restauración de la sesión, buscar y reemplazar con expresiones regulares, macros, marcadores, un explorador de archivos, Ir a cualquier cosa, una paleta de comandos y un minimapa, sin cuenta y sin telemetría. La versión completa, que llega al Mac App Store, añade IntelliSense, compilar y ejecutar, un depurador de Python, SQL sobre bases de datos y sobre archivos de Excel o CSV, integración con GitHub y un asistente de IA que funciona con tu propia clave de Claude, un servicio compatible con OpenAI o un modelo local. Hay una versión para iPadOS planeada.

Normas de marca

  • Escribe el nombre como jplus2, todo en minúsculas, incluso al principio de una frase. A la edición gratuita llámala jplus2 Lite.
  • Usa el icono tal como se entrega, sin cambiar sus colores, proporciones ni la J y el 2.
  • Enlaza, por favor, a jplus2.com.
  • Colores del sitio: índigo #4257f5, violeta #6a3de8, coral #ef6f6c, texto #1d1d1f.

Conviene saber antes de escribir

  • jplus2 es la versión 1.0 de un solo desarrollador y es de código cerrado. No tiene sistema de complementos.
  • La versión completa aún no está en el Mac App Store. Hoy solo se puede descargar jplus2 Lite.
  • El instalador de Lite aún no está notarizado por Apple, así que macOS pide confirmar que lo abras: Ajustes del Sistema ▸ Privacidad y seguridad ▸ Abrir igualmente.
  • Las comparaciones de este sitio citan las páginas de cada fabricante y dicen cuándo se consultaron.

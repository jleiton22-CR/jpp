Un cliente SQL de Databricks y Snowflake para Mac, dentro de tu editor de código

Última actualización: 2026-11-21

La versión completa de jplus2 se conecta a Databricks y Snowflake mediante sus propias API de SQL. Escribes la consulta junto a tu código, pulsas un atajo y lees los resultados en una tabla.

A qué puedes conectarte

  • Databricks en Azure, AWS y GCP.
  • Snowflake.

Ambos usan sus propias API de SQL, así que no hay que instalar antes un cliente de línea de comandos. La misma pestaña SQL también funciona con Azure SQL, SQL Server y Synapse, PostgreSQL, MySQL y MariaDB, archivos SQLite y archivos de Excel y CSV.

Cómo funciona

  1. Elige Database ▸ Manage Connections… (⇧⌘D) y añade una conexión a Databricks o Snowflake.
  2. Abre una pestaña SQL y escribe tu consulta.
  3. Pulsa ⌘↩ para ejecutar la selección o la sentencia donde está el cursor.
  4. Los resultados aparecen en una tabla bajo tu código. Cópialos o expórtalos como CSV.

Las contraseñas, los tokens y las claves de API se guardan en el Llavero de macOS.

Por qué hacerlo desde un editor

Los cuadernos y las consolas web separan la consulta del script que la usa. En jplus2 el SQL, el código Python o de shell que lo rodea, GitHub y el asistente de IA están en una sola ventana: puedes consultar un almacén de datos, ajustar un script y confirmar el cambio sin cambiar de app.

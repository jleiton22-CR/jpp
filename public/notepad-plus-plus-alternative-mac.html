Notepad++ for Mac: a native alternative

Last updated: 2026-11-15

Notepad++ is a Windows program, so it does not run natively on a Mac. If you are coming from Windows and want something similar, this page lists what you can use and where jplus2 Lite fits, including what it does not do.

Can you use Notepad++ on a Mac?

Notepad++'s own website describes it as a program for the Windows environment, built on the Scintilla editing component and released under the GNU General Public License. A community project, Nextpad++, ports it to macOS; according to its website it is free, open source (GPL v3) and supports plugins ported from the Windows version.

What jplus2 Lite gives you

jplus2 Lite is a free, native Mac editor. It is built on Scintilla 5 too, so the editing core will feel familiar. It includes:

  • Syntax colouring and code folding for 95 languages
  • Tabs with session restore
  • Find, replace and mark in normal, extended and regular-expression modes, with a results window
  • Macros: record, play back and run several times
  • Bookmarks: toggle, jump, and cut, copy or remove the bookmarked lines
  • A file explorer sidebar
  • Go to Anything (⌘P), the Command Palette (⇧⌘P) and a minimap
  • Encodings (UTF-8, UTF-8 with BOM, UTF-16, ANSI) and line-ending conversion
  • Line tools such as sort, duplicate, join and trim
  • Light and dark appearance that follows macOS

Where jplus2 is not a replacement

  • If you depend on specific Notepad++ plugins, jplus2 has no plugin system and will not replace them.
  • jplus2 is for Apple devices only: a Mac app today, with an iPadOS version planned.
  • It is version 1.0 from a single author, so it has less mileage on huge files and unusual workflows than long-established editors.

Other native editors on Mac

Nextpad++ (the community port above), CotEditor, BBEdit, CodeEdit and Nova are all native Mac editors. Try two or three and keep the one that fits how you work.

When the full version helps

The full jplus2, coming to the Mac App Store, adds IntelliSense, compile and run, a Python debugger, SQL on databases and on Excel or CSV files, GitHub and an AI assistant in the same window. See jplus2 Lite and the full version.

Frequently asked questions

Is there an official Notepad++ for Mac?
Its official website describes a Windows program. A community port, Nextpad++, exists for macOS.
Is jplus2 Lite free?
Yes. It is a free download of about 5.6 MB, with no account.
Does jplus2 Lite have plugins?
No. Everything it does is built in.
Does jplus2 Lite send my data anywhere?
No. jplus2 Lite makes no network connections of its own. The Help menu only opens this website, an email message or the donation page in your browser when you choose them.

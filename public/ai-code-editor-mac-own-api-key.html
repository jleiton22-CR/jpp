An AI code editor for Mac that uses your own API key

Last updated: 2026-11-16

Some editors tie their AI assistant to a subscription. The full version of jplus2 works the other way: you bring your own model. Connect Claude with your API key, any OpenAI-compatible service, or a model running on your Mac.

How it works

  • AI ▸ Assistant (⌃⌘A) opens a chat panel beside the editor.
  • With Include the current file on, your question goes with the file in front of you and your selection.
  • Insert and Replace Selection apply the code from the last answer as one undo step.
  • The AI menu has ready-made questions: Explain Code, Find Problems, Improve Code, Add Comments and Write Tests.

Agent mode

Tick Agent under the conversation, or choose AI ▸ Agent Mode. The assistant can then read files and list folders in the folder you opened, propose changes and propose terminal commands, and keep going until the task is done.

  • Each change opens as a diff with Apply and Cancel.
  • Each command appears in the Terminal panel with Run and Reject. When it ends, the output goes back to the assistant.
  • Paths outside the opened folder are refused, and the agent stops by itself after 20 steps.
  • jplus2 reads AGENTS.md, CLAUDE.md or .cursorrules from the folder, keeps per-project memories and attaches files you name with @name.

What the assistant reads and what your commands print is sent to the model's provider (or your gateway) so it can continue. Do not approve a command that prints secrets.

Like Cursor and Windsurf, it works as an agent on your project. Unlike a subscription, you choose the model and pay your provider directly.

Choose your model

OptionWhat you need
Claude (Anthropic)An API key from console.anthropic.com. Usage is billed to your account. Answers appear as they are written.
Any OpenAI-compatible serviceThe service's address and key.
A model on your MacA local server that speaks the OpenAI chat API, for example Ollama at http://localhost:11434/v1.

What happens to your code

API keys are kept in the macOS Keychain. Your code leaves the Mac only when you ask the assistant something. With a local model through Ollama it does not leave your Mac at all. jplus2 itself has no account and no analytics.

Setting up a local model

  1. Install Ollama and download a model with it.
  2. In jplus2, choose AI ▸ Model Connections… and pick the OpenAI-compatible option.
  3. Enter http://localhost:11434/v1 and the name of the model you downloaded.

Is it available now?

The assistant is part of the full version of jplus2, which is on the Mac App Store. jplus2 Lite, the free download, does not include it.

Frequently asked questions

Do I need a subscription?
There is no subscription to jplus2. You use your own API key, or a local model.
Where is my API key stored?
In the macOS Keychain.
Does it work without an internet connection?
With a local model through Ollama, yes.

jplus2's AI agent compared with Cursor, Windsurf, VS Code, Sublime Text and Nextpad++

Last updated: 2026-11-16

On 16 November 2026 the full version of jplus2 gained an Agent mode and the project tools around it. Here is what was added, and how it compares with each editor on its own, using only what their public sites and documentation say.

What was added

  • Agent mode. The assistant can list and read files in the folder you opened, propose file changes and propose terminal commands, step by step. You approve every one.
  • Changes as a diff. Each change opens with Apply and Cancel before anything is written.
  • Commands in the Terminal panel. Each command waits for Run or Reject, and its output and exit status go back to the assistant.
  • Project instructions. It reads AGENTS.md, CLAUDE.md or .cursorrules from your folder.
  • Memories and @files. One-line memories per project, and files attached by writing @name (up to 8 text files).
  • Your own prompts and reviews. Custom commands from ai-commands.json, and reviews of uncommitted changes or pull requests.
  • Gateways. A company gateway with a renewable key, and an import from Claude Code's settings.json.

Full version only. None of this is in jplus2 Lite, the free download.

Is it available now?

Agent mode is part of the full version of jplus2, which is on the Mac App Store. jplus2 Lite, the free download, does not include the assistant or Agent mode.

Frequently asked questions

Is Agent mode in jplus2 Lite?
No. It is part of the full version, which is on the Mac App Store.
Can the agent change my files without asking?
No. Every file change opens as a diff to apply or cancel, and every command waits for you to press Run.
Does it work with a project set up for Cursor?
It reads .cursorrules and AGENTS.md files, so the instructions already in the project are used.
Is my code sent anywhere?
Only when you use the assistant, and to the model you chose. In agent mode, what it reads and what your commands print is sent so it can continue.

Un editor de código con IA para Mac que usa tu propia clave de API

Última actualización: 2026-11-16

Algunos editores atan su asistente de IA a una suscripción. La versión completa de jplus2 funciona al revés: traes tu propio modelo. Conecta Claude con tu clave de API, cualquier servicio compatible con OpenAI o un modelo que se ejecute en tu Mac.

Cómo funciona

  • AI ▸ Assistant (⌃⌘A) abre un panel de chat junto al editor.
  • Con Include the current file activado, tu pregunta va con el archivo que tienes delante y tu selección.
  • Insert y Replace Selection aplican el código de la última respuesta como un solo paso de deshacer.
  • El menú AI trae preguntas listas: Explain Code, Find Problems, Improve Code, Add Comments y Write Tests.

Modo Agente

Marca Agent bajo la conversación, o elige AI ▸ Agent Mode. El asistente puede entonces leer archivos y listar carpetas dentro de la carpeta que abriste, proponer cambios y proponer comandos de terminal, y seguir hasta terminar la tarea.

  • Cada cambio se abre como diff con Apply y Cancel.
  • Cada comando aparece en el panel Terminal con Run y Reject. Al terminar, la salida vuelve al asistente.
  • Las rutas fuera de la carpeta abierta se rechazan y el agente se detiene solo tras 20 pasos.
  • jplus2 lee AGENTS.md, CLAUDE.md o .cursorrules de la carpeta, guarda memorias por proyecto y adjunta los archivos que nombras con @nombre.

Lo que el asistente lee y lo que imprimen tus comandos se envía al proveedor del modelo (o a tu gateway) para que pueda continuar. No apruebes un comando que imprima secretos.

Como Cursor y Windsurf, trabaja como agente sobre tu proyecto. A diferencia de una suscripción, tú eliges el modelo y pagas directamente a tu proveedor.

Qué pasa con tu código

Las claves de API se guardan en el Llavero de macOS. Tu código sale del Mac solo cuando le preguntas algo al asistente. Con un modelo local mediante Ollama no sale de tu Mac en absoluto. jplus2 en sí no tiene cuenta ni analíticas.

Configurar un modelo local

  1. Instala Ollama y descarga un modelo con él.
  2. En jplus2, elige AI ▸ Model Connections… y escoge la opción compatible con OpenAI.
  3. Escribe http://localhost:11434/v1 y el nombre del modelo que descargaste.

Preguntas frecuentes

¿Necesito una suscripción?
No hay suscripción a jplus2. Usas tu propia clave de API o un modelo local.
¿Dónde se guarda mi clave de API?
En el Llavero de macOS.
¿Funciona sin conexión a internet?
Con un modelo local mediante Ollama, sí.

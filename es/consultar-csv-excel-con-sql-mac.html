Consultar archivos CSV y Excel con SQL en un Mac

Última actualización: 2026-11-15

No necesitas un servidor de bases de datos para ejecutar SQL sobre una hoja de cálculo. Esta página muestra un método gratis con la herramienta sqlite3 que ya trae tu Mac, y cómo hace lo mismo la versión completa de jplus2 dentro de un editor de código.

Método 1: sqlite3 en Terminal (gratis, ya está en tu Mac)

macOS incluye la herramienta de línea de comandos sqlite3. Para un archivo CSV llamado people.csv cuya primera fila tiene los nombres de las columnas:

sqlite3 :memory: -cmd ".mode csv" -cmd ".import people.csv people" -cmd ".headers on" -cmd ".mode column" \
  "select city, count(*) as n from people group by city order by n desc;"

La primera fila pasa a ser los nombres de las columnas, el archivo se carga en una base de datos en memoria y la consulta imprime una tabla. Un libro de Excel (.xlsx) hay que exportarlo antes a CSV.

Método 2: jplus2, en un editor de código

En la versión completa de jplus2, un libro de Excel o un archivo CSV es una conexión de base de datos. Cada hoja se convierte en una tabla de una base de datos SQLite en memoria, y la consultas desde una pestaña SQL.

  1. Elige Database ▸ Manage Connections… (⇧⌘D) y añade una conexión de tipo libro de Excel o archivo CSV.
  2. Abre una pestaña SQL y escribe tu consulta.
  3. Pulsa ⌘↩ para ejecutar la selección o la instrucción donde está el cursor.
  4. Los resultados aparecen en una cuadrícula. Cópialos o expórtalos como CSV.

La misma pestaña SQL también funciona con archivos SQLite, Databricks y Snowflake.

Otras apps

Hay aplicaciones dedicadas, algunas en el Mac App Store, y herramientas de código abierto como DuckDB que también consultan archivos con SQL. Elige la que encaje con la frecuencia con la que lo haces.

Preguntas frecuentes

¿Necesito instalar una base de datos?
No. Para archivos de Excel y CSV, jplus2 usa una base de datos SQLite en memoria.
¿Puedo exportar los resultados?
Sí. Copia la cuadrícula o expórtala como CSV.
¿Mi archivo sale de mi Mac?
No. Los archivos se quedan en tu Mac. Solo las conexiones que configuras tú, como Databricks o Snowflake, usan la red.

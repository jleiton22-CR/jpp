Soporte

Esta página responde las preguntas más comunes. La guía completa está dentro de la app: elige Help ▸ J++ Guide.

Instalar J++

Abre la imagen de disco descargada y arrastra J++ a tu carpeta Aplicaciones. J++ necesita macOS 12 o posterior y funciona en Mac con Apple Silicon y con Intel.

Si macOS dice que no puede comprobar la app la primera vez que la abres, abre Ajustes del Sistema ▸ Privacidad y seguridad, busca el mensaje sobre J++ y pulsa Abrir igualmente.

Compilar o Ejecutar dice que una herramienta viene con Xcode

J++ usa las herramientas de desarrollo de Apple para C, C++, Objective-C, Swift, Python y Git. Instala Xcode desde el App Store, o ejecuta xcode-select --install en Terminal, y vuelve a intentarlo.

Un lenguaje aún no tiene compilador

Elige Run ▸ Manage Compilers…. La lista muestra qué compiladores están instalados; marca los que faltan y pulsa Install Selected para descargarlos con Homebrew, npm o pip.

Ejecutar SQL

Abre Database ▸ Manage Connections… (⇧⌘D), añade una conexión y pulsa ⌘↩ en una pestaña SQL. Los resultados aparecen debajo de tu código. PostgreSQL, MySQL y SQL Server necesitan sus clientes de línea de comandos, que puedes instalar con Homebrew.

Depurar Python

Haz clic en el margen junto a una línea para poner un punto de interrupción y pulsa F6. Usa la barra de herramientas para avanzar paso a paso.

La versión del Mac App Store

Apple exige que las apps del App Store funcionen en un entorno aislado, así que esa versión usa solo las herramientas de macOS y de Xcode. No puede iniciar un programa que acaba de compilar en C, C++ u Objective-C, y no ofrece conexiones a PostgreSQL, MySQL ni SQL Server. Cuando un compilador necesite otros archivos de la misma carpeta, pulsa Allow Folder Access… en el panel de salida.

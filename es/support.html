Soporte

Esta página responde las preguntas más comunes. La guía completa está dentro de la app: elige Help ▸ jplus2 Guide.

Instalar jplus2

Abre la imagen de disco descargada y arrastra J++ Lite a tu carpeta Aplicaciones. jplus2 necesita macOS 12 o posterior y funciona en Mac con Apple Silicon e Intel.

Si macOS dice que no puede comprobar la app la primera vez que la abres, abre Ajustes del Sistema ▸ Privacidad y seguridad, busca el mensaje sobre J++ Lite y pulsa Abrir igualmente. La versión del Mac App Store no muestra este mensaje.

¿jplus2 Lite o la versión completa?

jplus2 Lite es gratis y se puede descargar desde este sitio web. Es un editor: resaltado de sintaxis para 95 lenguajes, pestañas, buscar y reemplazar, explorador de archivos, Ir a cualquier cosa, paleta de comandos y minimapa.

El jplus2 completo está disponible en el Mac App Store. Añade IntelliSense, Compilar y Ejecutar, el depurador de Python, SQL, GitHub, el asistente de IA y la guía integrada. Puedes tener las dos instaladas.

jplus2 para iPad

Una versión para iPad está planeada para el próximo lanzamiento. Empieza como un editor enfocado, con pestañas, buscar y reemplazar, autocompletado y compatibilidad con Archivos. Los detalles pueden cambiar antes de publicarla.

Compilar o Ejecutar dice que una herramienta viene con Xcode

jplus2 usa las herramientas de desarrollo de Apple para C, C++, Objective-C, Swift, Python y Git. Instala Xcode desde el App Store, o ejecuta xcode-select --install en Terminal, y vuelve a intentarlo.

Un lenguaje aún no tiene compilador

Elige Run ▸ Manage Compilers…. La lista muestra qué compiladores están instalados; marca los que faltan y pulsa Install Selected para descargarlos con Homebrew, npm o pip.

Ejecutar SQL

Abre Database ▸ Manage Connections… (⇧⌘D), añade una conexión y pulsa ⌘↩ en una pestaña SQL. Los resultados aparecen debajo de tu código. PostgreSQL, MySQL y SQL Server necesitan sus clientes de línea de comandos, que puedes instalar con Homebrew.

Depurar Python

Haz clic en el margen junto a una línea para poner un punto de interrupción y pulsa F6. Usa la barra de herramientas para avanzar paso a paso.

Encontrar archivos, símbolos y comandos

Pulsa ⌘P para abrir un archivo escribiendo unas pocas de sus letras. En el mismo panel, @ muestra los símbolos del archivo actual, : va a una línea, # busca en el texto del archivo y > (o ⇧⌘P) ejecuta cualquier comando de los menús. View ▸ Show Minimap muestra u oculta el mapa del archivo.

GitHub

Conecta tu cuenta con GitHub ▸ Account…. Después, GitHub ▸ Browse Repositories… (⌥⌘G) muestra las carpetas y los archivos de tus repositorios sin clonarlos, y permite crear o fusionar pull requests.

Apariencia clara u oscura

Elige jplus2 ▸ Settings ▸ Appearance: Match macOS (el valor por defecto), Light o Dark. La elección cambia toda la app y los colores del código.

La versión del Mac App Store

Apple exige que las apps del App Store funcionen en un entorno aislado, así que esa versión usa solo las herramientas de macOS y de Xcode. No puede iniciar un programa que acaba de compilar en C, C++ u Objective-C, y no ofrece conexiones a PostgreSQL, MySQL ni SQL Server. Cuando un compilador necesite otros archivos de la misma carpeta, pulsa Allow Folder Access… en el panel de salida. Claude CLI tampoco se puede iniciar desde el entorno aislado, así que el botón del asistente siempre abre el chat.

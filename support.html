Support

This page answers the most common questions. The full guide is inside the app: choose Help ▸ jplus2 Guide.

Installing jplus2

Open the downloaded disk image and drag jplus2 Lite to your Applications folder. jplus2 needs macOS 12 or later and runs on Apple silicon and Intel Macs.

If macOS says it cannot check the app the first time you open it, open System Settings ▸ Privacy & Security, find the message about jplus2 Lite and press Open Anyway. The Mac App Store version does not show this message.

jplus2 Lite or the full version?

jplus2 Lite is free and can be downloaded from this website. It is an editor: syntax colouring for 95 languages, tabs, find and replace, a file explorer, Go to Anything, the Command Palette and a minimap.

The full jplus2 is available on the Mac App Store. It adds IntelliSense, Compile and Run, the Python debugger, SQL, GitHub, the AI assistant and the built-in guide. You can keep both installed.

jplus2 for iPad

A version for the iPad is planned for the next release. It starts as a focused editor with tabs, find and replace, completion and Files support. Details may change before it is released.

Compile or Run says a tool comes with Xcode

jplus2 uses Apple's developer tools for C, C++, Objective-C, Swift, Python and Git. Install Xcode from the App Store, or run xcode-select --install in Terminal, then try again.

A language has no compiler yet

Choose Run ▸ Manage Compilers…. The list shows which compilers are installed; tick the missing ones and press Install Selected to download them with Homebrew, npm or pip.

Running SQL

Open Database ▸ Manage Connections… (⇧⌘D), add a connection, then press ⌘↩ in a SQL tab. Results appear under your code. PostgreSQL, MySQL and SQL Server need their command line clients, which you can install with Homebrew.

Debugging Python

Click the margin next to a line to set a breakpoint, then press F6. Use the toolbar to step through the code.

Finding files, symbols and commands

Press ⌘P to open a file by typing a few of its letters. Inside the same panel, @ lists the symbols of the current file, : goes to a line, # searches the file's text and > (or ⇧⌘P) runs any menu command. View ▸ Show Minimap shows or hides the map of the file.

GitHub

Connect your account with GitHub ▸ Account…. Then GitHub ▸ Browse Repositories… (⌥⌘G) shows the folders and files of your repositories without cloning them, and lets you create or merge pull requests.

Light or dark appearance

Choose jplus2 ▸ Settings ▸ Appearance: Match macOS (the default), Light or Dark. The choice sets the whole app and the colours of the code.

The Mac App Store version

Apple requires App Store apps to run in a sandbox, so that version uses only the tools from macOS and Xcode. It cannot start a program it has just built from C, C++ or Objective-C, and it does not offer PostgreSQL, MySQL or SQL Server connections. When a compiler needs other files in the same folder, press Allow Folder Access… in the output pane. Claude CLI cannot be started from the sandbox either, so the assistant button always opens the chat.
